Plate 2 · the five open questions

You left five things undecided. Running it decided four.

The brief listed these under “Open design questions for CID itself — not decided.” They turned out to be the load-bearing ones.

01

Agent, or workflow?settled

Both, split by kind of work. Ten deterministic scripts and five agent types. The rule that emerged: an agent is for judgement, a script is for counting. Three wave-1 sheets each spent ~150k tokens rediscovering one string comparison a script finds in milliseconds — so cid:verify now runs before any verifier is dispatched, and the verifier’s budget goes on the half that needs a mind.

02

What does a department output — prose, or a structured artifact?settled

A structured artifact, and this was the expensive lesson. Wave 1 produced 35 sheets of which 78% had no data form — 6,297 lines no build step could read. Prose was never the problem; prose with no data beside it was. Every sheet now carries a manifest block, or states in one line why its subject has none and names the key it would need. As of today: zero sheets fail that.

03

How do departments disagree?settled

A verifier per category, issuing revision requests that name the file and the fix — and for the hard case, a shared block naming one definer and its readers. That exists because two domains inverted twice in three rounds over one field, each adopting the other’s previous position: both correct alone, contradictory together. Deadlocks that survive a round get ruled from outside.

04

Does CID feed back into stage 0?still open

No return path was built. Findings loop inside CID — a category can fail and be re-run — but nothing routes a defect back to the concept stage. If a design decision turns out to be impossible, that still ends in a human re-running the interview. This is the one question of the five that running the pipeline did not answer.

05

How does CID output reach ui-forge?answered by not happening

It doesn’t. The question assumed ui-forge was on the path to the build. It isn’t — it renders screens, is fed by stage 0 directly, and sits outside the build order on purpose. CID reaches the game through bridge and the architect instead. The bridge the brief called “gap 2” got built; it just wasn’t the bridge the brief expected.

Revisions · at handover

Seven changes before it ran once

Made while turning the graph into a runnable config — each one a hole the drawing had, found by trying to execute it rather than by reading it.

  • +Balance & Tuning Nothing in the graph owned the numbers.
  • +Onboarding Nothing designed the first minute.
  • +Checks on all nine category verifications Every verification node existed; none said what it checked.
  • ↔Theme wired to all nine categories It reached three domain leads. Art and Audio were told to match a tone document they were never sent.
  • ↺A return path for cross-category verification Its only edge went to the Build CEO, so every catch was terminal — the pass could find a problem and had nowhere to send it.
  • +A Build Capability Registry So a spec naming a pattern the compiler can’t produce fails at CID, not three stages later.
  • ↕Tech and UI/UX moved ahead of Art Performance budgets constrain art detail, so Art was being asked to decide first and be overruled after.

Revisions · from running it

Six more the drawing could not have shown

These only appear once real work goes through. None is a disagreement with the design; each is a cost or a failure the design was silent about.

  • ×One writer per sheet → one per domain Wave 1 spent ~6.3M input tokens to produce ~110k of sheets. 97% was input, most of it the same bytes delivered once per sheet, because every writer discovered its own context by reading files. Batching by domain also removed sibling collisions: a writer holding all of a domain’s sheets cannot contradict itself.
  • +Context became a derivation, not a search An agent that reads 26 sibling sheets to learn where its subject stops, or re-fetches a page another agent fetched an hour ago, is paying to re-derive what a parser states once. Measured after: ~11× cheaper.
  • +The mechanical half left the verifiers Index-matches-disk, criteria-present, one-key-one-owner — none of that needed a mind, and all of it was being paid for at agent rates.
  • +bridge — a stage the drawing didn’t have Sheets had to become a validated manifest before anything could read them. The drawing crossed that span with a single arrow.
  • +The contract split in two Two build trials measured what actually stopped a builder, and roughly 15 of 21 stops were not creative questions — they were require paths, collection shapes, and who writes a Humanoid property. So the architect answers how it gets built and CID answers what the game is.
  • +Citations became checkable The single most-repeated defect across seven waves was not a bad decision — it was a field path quoted from memory. One phantom appeared in five sheets, in three spellings, across three categories, and the key had never had it. One of those was a runtime condition, and a nil compare in Luau is silently falsy, so the game state it guarded would simply never have fired.

The comparison

What the drawing got right was the part it refused to fix

The lineup in the brief — fourteen departments in five waves — is now fifty-five domains in seven. On a normal reading that is the plan being wrong by a factor of four.

Except the brief said this, in bold, before anything ran:

“This lineup is expected to change and nothing in stage 0 depends on it. Do not treat the table above as a spec. Treat it as one plausible slicing.”

That is why the count could quadruple without a rewrite. The sheets were organised by the design’s dependency layers rather than by an org chart, so a reader routes itself by subject — and re-slicing the departments left every sheet still valid. The one prediction the brief made about its own weakness is the one that held.

The parts that needed the most work were the parts stated with the most confidence: a single arrow where two stages belonged, verification nodes with no checks in them, and a Theme department wired to three of the nine categories that were waiting on it.
