arga · pipeline as of 31 July 2026

Roblox game, start to finish, in two kinds of step

Every seam in this pipeline is either an agent (judgement, expensive, never reproducible twice) or a derivation (code, free, identical every run). The architecture is one long argument for moving work from the first kind into the second. Prose has to be re-interpreted by whoever reads it next, and interpretation is where two build agents quietly become two different games.

Three rules that are load-bearing

Everything above follows from these. They are in the repo's CLAUDE.md, and breaking one is how the pipeline regresses.

Seams are derivations, never prompts

Every handoff between stages is pure code: compose(brief, theme), the manifest merger, the context pack. Prose gets re-interpreted downstream, and interpretation is where visual and design variance re-enters.

Prefer changes that make bad output impossible

Tokens, validators and lint passes beat making one screen prettier by hand. The schema refuses two tiers that share a shape, so rarity stays readable with colour thrown away. Nobody has to remember that.

A budget on prose, never on checks

Learned the hard way this week. Given a flat line cap, a writer cut a twelve-entry exclusion list to six and dropped every named object, keeping the paragraphs that explained itself.

A build agent cannot count not spooky. It can count cobwebs. Tables are now exempt from the budget.
