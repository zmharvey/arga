# 01 — Register baseline

**Domain:** Tone · **Category:** Theme & Narrative · **Wave:** 1

## Decision

The register is **quiet competence**. The player is someone doing careful work in a place that
has been waiting, and the game speaks the way a person absorbed in a task speaks: plainly,
without urgency, and without congratulating itself.

Concretely: the game **observes** rather than **exhorts**. "You found a bronze sundial" is the
register. "Amazing! You got a Bronze Sundial!!" is not.

## Why

- **"Unhurried" is the operative adjective, and it is a prohibition on language, not just on
  pacing.** `[brief: soft]` A game with no timer, no failure and no reset (`[brief: binding]`,
  `02-GAMEPLAY.md`) has nothing to be urgent about. Urgency in copy would be the game
  performing a tension its systems deliberately do not have.
- **"Aged" points at restraint rather than at ornament in the writing.** The `fantasy-ornate`
  vibe key `[brief: soft]` carries ornament in the *art*. If the copy is also ornate, the two
  compound and the result reads as pastiche. Ornate visuals with plain language is a
  deliberate split.
- **The reference genre is loud, and this game is positioned out of it.** The brief moves the
  game to "restoration, not incremental" `[brief: binding]` R4 Q2 at a stated cost. Adopting
  incremental-simulator copy conventions would undo that positioning in the one place the
  player actually reads.
- **Warmth comes from what is noticed, not from volume.** `[cid: decided]` The cheapest warmth
  available to this game is specificity about the thing uncovered, which costs nothing and
  reinforces the collection as the differentiator `[brief: binding]` R1 Q1.

`[unverified — dry run]` Whether the reference's copy register is as loud as assumed is not
sourced. If it turns out to be plain, the third point weakens and the split is less of a
departure than claimed.

## Consequences for other work

- **All on-screen copy** inherits an observational voice: no exclamation marks, no
  second-person exhortation, no superlatives applied by the game to the player's actions.
- **Music and ambient** sit under action sound rather than driving it. A register this quiet
  cannot survive a score that is doing emotional work the systems are not.
- **Naming** should favour plain concrete nouns over grandiose compounds. This is a constraint
  on the canonical term list, not a request to name anything.
- **Reward moments** are allowed to be visually large (see `04-emotional-beat-map.md`) while
  staying verbally plain. The peak is in the picture and the sound, not in the adjective.

## Acceptance criteria

1. No copy string anywhere in the game contains an exclamation mark.
2. No copy string contains an urgency term: *now, hurry, quick, fast, don't miss, last
   chance, limited, running out*.
3. Every reward and progress message is phrased as an observation of what happened, not as
   praise directed at the player. Checkable form: the string does not contain a
   second-person superlative (*you're amazing, great job, incredible, nice work*).
4. Ambient and music bus levels sit at or below the action-sound bus at default settings.
