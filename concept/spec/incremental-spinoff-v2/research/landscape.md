# Research — the "X Incremental" landscape

Occupancy research, run **before** offering any theme. This exists because the previous
run verified that grass, lumber and ore were taken, let the developer pick snow, and never
checked snow. Snow was taken three times over.

## The single most important finding

**This is a commodity genre with a standardised store description.** Three games by at
least two different studios ship near-identical copy:

> *"A relaxing {noun} simulator game where the more you rebirth and upgrade, the more fun
> the game becomes, with the ability to unlock new islands and upgrades."*

- `[🌱] Grass Incremental Simulator` — Unequal Games [research: https://www.roblox.com/games/133086043677134/Grass-Incremental-Simulator]
- `Scrap Incremental 🧲` — "A relaxing magnet simulator game" [research: https://www.roblox.com/games/92876036717311/Scrap-Incremental]
- `Lumber Incremental Simulator` — "A relaxing tree-cutting incremental game" [research: https://www.roblox.com/games/109187599373995/Lumber-Incremental-Simulator]
- `[UPDT🍂] Leaves Incremental 🍂` — **PrestigeLabs Studios**, a different developer, same
  formula: "A relaxing leaf-gathering simulator! Collect, upgrade, and explore colorful
  autumn worlds!" [research: https://www.roblox.com/games/113380129609386/Leaves-Incremental]

**Consequence: the noun is not a differentiator.** Nouns are being consumed faster than a
new game can ship, by multiple studios, using the same skeleton and the same marketing
sentence. Choosing an "unoccupied" theme is a race that cannot be won by picking harder.

## Snow, specifically — what the previous run would have duplicated

`Snow Incremental Simulator` by NOOBISTUDIOS
[research: https://www.roblox.com/games/138763709974342/Snow-Incremental-Simulator]:

- *"Shovel up snow to collect snowflakes"* — the proximity-harvest verb
- upgrades to *"snow value, rate, and time it takes to fall"* — **the exact three axes**
- *"purchase better and bigger tools"* — the visible tool ladder
- *"Rebirth to unlock better rewards"*
- leaderboards
- self-described as **"heavily inspired by Grass Cutting Incremental"**

`Snow Shoveling Simulator` (Virtual Block Studio, page updated March 2026) additionally has
*shovels → snow blower → snow plow* and pets, in Winterville, selling snow to Frosty.
[research: https://roblox.fandom.com/wiki/Virtual_Block_Studio/Snow_Shoveling_Simulator]

The v1 spec described a kid with a shovel upgrading toward a plow, clearing snow, with three
upgrade axes and rebirth. That is these two games.

## What is genuinely uncontested

Across everything searched, **no game in this family surfaced a hidden-object collection
layer** — objects revealed by harvesting that enter a permanent, set-structured index.
Treasure Hunt Simulator digs for treasure, but it *is* a digging game, not a harvest-plus-
discovery hybrid.

Also notable: **Leaves Incremental's description does not mention rebirth at all**, so parts
of this family are thinner than the reference rather than deeper.

## Not verified

- Whether the shared store description means shared code, a template, or copying.
- Player counts for anything except the reference — no CCU or visit figures gathered for the
  competitors, so "taken" here means "exists", not "successful".
- Whether the untouched themes (rust, mould, cobweb, vines, clouds) are actually free or
  simply poorly indexed. Four searches surfaced nothing; that is weak evidence.
